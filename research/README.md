# Research Notes

資料を読んだ直後の知見を、著作権を侵害しない抽象化メモとして残す場所。

## 1件の推奨フォーマット

```md
## Topic

### Sources
- 出典名 / 年 / 号 / URL

### Observations
- 原文をコピーせず短い事実として記録

### Mechanisms
- それがプレイヤーの判断・学習・感情にどう作用するか

### Generalized Principles
- 固有ゲームに依存しない設計原則

### Transfer Ideas
- Action:
- Racing:
- RPG:
- Puzzle:
- Mobile:

### Playtest Questions
- 実際のゲームで確認できる質問
```

## Promotion Rule

単発の面白い事例は research に留める。

異なる複数資料・複数ゲームで繰り返し確認でき、汎用性が高い知見だけを `docs/core-principles.md` へ昇格する。
