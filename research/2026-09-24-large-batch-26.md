## Observation → Mechanism → Generalized Principle → Transfer → Playtest Question

### 1. Random seed sampling under-tests rare failures
**Observation:** Large procedural spaces can contain tiny regions with catastrophic geometry, impossible resource states or degenerate strategies.
**Mechanism:** Uniform random sampling spends most tests on already-common behavior clusters.
**Generalized Principle:** After baseline random coverage, actively search for failure boundaries and under-covered behavior cells.
**Transfer:** Mutate seeds/parameters around near-failures; reward agents for maximizing invariant violations, extreme path cost or exploit yield.
**Playtest Question:** Does the test budget keep rediscovering ordinary seeds while rare severe failures remain unsearched?

### 2. The adversary should optimize failure evidence, not visual weirdness
**Observation:** Novel-looking content is not necessarily dangerous content.
**Mechanism:** A novelty objective can drift toward harmless cosmetic extremes.
**Generalized Principle:** Adversarial search objectives should be tied to player-relevant failure signals.
**Transfer:** Search for low resource slack, high unavoidable damage, navigation ambiguity, exploit reward/minute, unreachable goals, extreme recovery delay or agent disagreement.
**Playtest Question:** Are adversarial seeds actually exposing gameplay risk, or merely unusual screenshots?

### 3. Near-failures are more informative than obvious invalid seeds
**Observation:** Completely broken seeds are easy for hard invariants to reject; borderline valid seeds expose fragile design margins.
**Mechanism:** Small parameter changes around the validity boundary reveal sensitivity and hidden assumptions.
**Generalized Principle:** Preserve and mutate near-threshold seeds as a regression corpus.
**Transfer:** Track distance-to-failure for clearance, jump margin, resource slack, timing window and route redundancy.
**Playtest Question:** Which currently valid seeds become invalid after the smallest legal perturbation?

### 4. Static validity and dynamic playability are separate gates
**Observation:** PCG research repeatedly combines structural checks with agent simulation; local or static constraints alone can miss dynamic failures.
**Mechanism:** Timing, moving hazards, enemy interaction and resource consumption only emerge during execution.
**Generalized Principle:** Use cheap static gates first, then dynamic simulation for survivors.
**Transfer:** topology/reachability/collision → scripted agent → policy-diverse agents → human review.
**Playtest Question:** Which seeds pass geometry checks but fail once enemies, timing or consumable resources are simulated?

### 5. Local plausibility does not imply global solvability
**Observation:** WFC-style local adjacency can reproduce convincing local patterns while missing long-range progression constraints.
**Mechanism:** Global dependencies exceed the representation's receptive constraint scope.
**Generalized Principle:** Validate constraints at the scale where the gameplay dependency exists.
**Transfer:** Check key-lock ordering, route loops, boss access, recovery placement and macro progression independently from local tile legality.
**Playtest Question:** Can every local region look valid while the complete run is impossible or strategically degenerate?

### 6. Semantic representations should encode affordance before appearance
**Observation:** Affordance-rich embeddings can generalize gameplay meaning across visually different tiles/assets.
**Mechanism:** Geometry/semantic role captures what the player can do, whereas pixels also encode irrelevant decoration.
**Generalized Principle:** Visual-semantic QA should compare collision/affordance/role layers before raw screenshots.
**Transfer:** Render or export semantic buffers: walkable, cover, hazard, landmark, interactable, enemy-space, occluder, objective.
**Playtest Question:** Are two screenshots judged different only because decoration changed while their affordance maps are nearly identical?

### 7. Depth disagreement is a useful geometric regression signal
**Observation:** Camera screenshots can hide z-fighting, clipping, terrain collapse or large geometry shifts behind similar color output.
**Mechanism:** Depth buffers expose structural surface displacement independent of texture/palette.
**Generalized Principle:** Canonical visual regression should include depth as well as RGB.
**Transfer:** Compare normalized depth histograms/maps and edge discontinuities at fixed cameras.
**Playtest Question:** Did geometry move materially even though the screenshot hash barely changed?

### 8. Segmentation diff should be role-weighted
**Observation:** Equal pixel error treats a moved cloud and a moved objective marker as equally important.
**Mechanism:** Gameplay roles have unequal semantic cost.
**Generalized Principle:** Weight semantic visual differences by decision relevance.
**Transfer:** objective/road/hazard/landmark/enemy silhouette changes receive higher QA weight than decorative foliage or particles.
**Playtest Question:** Does the visual diff prioritize changes that alter navigation, threat reading or targeting?

### 9. Solution/action traces are a cross-presentation diversity metric
**Observation:** PCG studies compare generated content through the action sequences required to solve it.
**Mechanism:** Action traces abstract away art while preserving interaction demands.
**Generalized Principle:** Use normalized solution traces to detect mechanical duplicates across visually unrelated seeds.
**Transfer:** Cluster move/turn/jump/attack/resource/branch event sequences; compare edit distance or learned embeddings.
**Playtest Question:** How many apparently distinct seeds collapse to essentially the same solution trace?

### 10. Coverage should be measured in behavior space, not seed count
**Observation:** Quality-Diversity methods explicitly map content into behavior/feature cells.
**Mechanism:** Ten thousand seeds can occupy the same few behavioral regions.
**Generalized Principle:** Test completeness is better approximated by discovered behavior clusters/cells than raw sample count.
**Transfer:** Maintain a coverage map over route entropy, pressure shape, resource slack, mechanic usage and strategy outcome.
**Playtest Question:** Did the last thousand seeds discover new behavior, or only add density to known clusters?

### 11. A stopping rule should use discovery saturation plus risk
**Observation:** Procedural spaces are usually too large for exhaustive testing.
**Mechanism:** Marginal discovery rate falls as common clusters are saturated, but severe rare failures may still justify continued search.
**Generalized Principle:** Stop a cohort only when new-cluster discovery and new-severe-failure rates remain below explicit thresholds across repeated windows.
**Transfer:** Track rolling `new_behavior_clusters / N` and `new_severe_failures / N`, with separate random and adversarial cohorts.
**Playtest Question:** Has discovery genuinely plateaued in both ordinary and adversarial sampling?

### 12. Coverage dimensions themselves can hide failures
**Observation:** A QD map only distinguishes what its selected descriptors encode.
**Mechanism:** Poor descriptors merge meaningfully different experiences into one cell.
**Generalized Principle:** Periodically challenge the descriptor set with human judgments and unexplained failures.
**Transfer:** If humans repeatedly distinguish seeds within one cell, add or revise descriptors rather than merely increasing sample count.
**Playtest Question:** Which human-perceived differences are invisible to the current behavior map?

### 13. Generator regression is a distribution shift problem
**Observation:** A new generator can retain validity and average difficulty while changing the population of strategies or experiences.
**Mechanism:** Means conceal mode collapse, missing tails and changed cluster proportions.
**Generalized Principle:** Compare distributions and cluster occupancy between generator versions.
**Transfer:** Track Jensen-Shannon/earth-mover-like distribution distances where appropriate plus added/lost behavior cells and worst-tail metrics.
**Playtest Question:** Which experience clusters disappeared or became overrepresented after the update?

### 14. Failure minimization makes procedural bugs actionable
**Observation:** A catastrophic seed can contain many irrelevant generated elements.
**Mechanism:** Developers need the smallest condition set that still reproduces the failure.
**Generalized Principle:** Automatically shrink procedural failures when the generator representation permits it.
**Transfer:** Remove rooms/enemies/decorators/parameter changes while re-running the failure predicate; save minimized repro plus original seed.
**Playtest Question:** Can the team reproduce the bug from a compact failing structure rather than inspecting a full world?

### 15. Agent disagreement is itself a diagnostic signal
**Observation:** Different policies/skill models can strongly disagree on the same generated level.
**Mechanism:** A seed may depend on one brittle strategy, exploit or skill-specific assumption.
**Generalized Principle:** High outcome disagreement should trigger review even when at least one agent succeeds.
**Transfer:** Compare novice/baseline/expert/safety/exploit-seeking policies and flag large completion/path/risk variance.
**Playtest Question:** Is the level robustly playable, or only solvable by one peculiar policy?

### 16. Rare-failure search and human playtests should exchange seeds
**Observation:** Automated adversaries discover machine-legible extremes; humans discover semantic frustration and confusion not captured by predicates.
**Mechanism:** Each exposes blind spots in the other's objective space.
**Generalized Principle:** Feed automated worst-N seeds to humans and convert recurring human failures into new machine predicates/descriptors.
**Transfer:** Maintain a loop: search → human classify → metric update → search again.
**Playtest Question:** Did the last human review create a new automated detector rather than only a one-off fix?

## Promotions

Strong enough for cross-project use:
- Procedural QA coverage is behavioral coverage, not number of seeds.
- Static validity and dynamic playability require separate gates.
- Rare-failure testing should deliberately search boundaries after random sampling.
- Semantic/depth/affordance buffers are more useful than screenshot hashes alone.
- Stopping criteria need discovery saturation plus severe-failure rate.
- Human findings should be converted into new automated predicates whenever possible.

## Production pipeline

1. Canonical seed regression corpus.
2. Large uniform random cohort.
3. Cheap structural invariants.
4. Dynamic policy-diverse simulation.
5. Behavior-cell / decision-signature assignment.
6. Novelty and severe-failure discovery accounting.
7. Adversarial mutation around near-failures and sparse cells.
8. Canonical RGB + depth + semantic/affordance buffers.
9. Role-weighted semantic visual diff.
10. Failure minimization and artifact preservation.
11. Human review of worst-N / novel-N / disagreement-N.
12. Update predicates/descriptors and repeat until rolling discovery thresholds saturate.
