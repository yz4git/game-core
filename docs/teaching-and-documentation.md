# Teaching & Documentation

マニュアル、ヘルプ、チュートリアルを一つにせず、知識と実践を分けて教授する。

## 1. Four layers

### Reference
操作一覧、用語、詳細仕様。

### Demonstration
実際にどう動くかを見る。

### Practice
安全に自分で実行する。

### Application
実戦でいつ使うか判断する。

すべてを長いチュートリアルへ詰め込まない。

## 2. Just-in-time teaching

必要になる直前に高度機能を教える。

開始時に全システムを説明しない。

## 3. Immediate transfer

説明した操作はすぐ使わせる。

説明 → 数十分後に使用、では知識が失われる。

## 4. Help stays accessible

チュートリアルを一度見逃しても、
- 操作一覧
- 技説明
- 用語
- 過去ヒント
を再確認できるようにする。

## 5. Tooltips for complex systems

複雑な戦略・シミュレーションでは、ポインタやフォーカスしたUIの機能をその場で説明できると、分厚いマニュアル依存を減らせる。

## 6. Do not remove depth to improve onboarding

深いシステムは残しつつ、
- 推奨設定
- 自動設定
- テンプレート
- 初期非表示
で入口を簡単にする。

## 7. Experienced players

チュートリアルはスキップ可能にする。

ただし新作固有の重要ルールは、短い実戦状況で確認できるようにする。

## Playtest

- 初回開始までに読む文章量
- 説明から初使用までの時間
- 5分後に覚えている操作数
- ヘルプ再確認までの手数
- 経験者が最短で本編へ入れるか
