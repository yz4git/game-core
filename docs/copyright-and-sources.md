# Copyright & Sources Policy

このリポジトリは、参照資料のコピー集ではなく、そこから得た**一般化されたゲームデザイン知識**を保存する。

## 保存してよいもの

- 自分の言葉で抽象化した設計原則
- 複数作品に共通するパターン
- プレイテスト用チェックリスト
- 「なぜ機能するか」という分析
- 別ジャンルへ転用可能なヒューリスティクス
- 出典名・号・年・URLなどの書誌情報
- 短い事実メモ

## 原則として保存しないもの

- 雑誌本文の長い引用
- スキャン画像
- 記事全文の翻訳
- 攻略記事の実質的な再現
- マップ・表・ランキング・誌面レイアウトのコピー
- 大量の固有文章を言い換えただけの近接要約

## 抽象化手順

資料から知見を得たら、次の順に変換する。

1. **Observation** — 何が行われていたかを短く把握
2. **Mechanism** — それがプレイヤーの何を変えるか分析
3. **Principle** — 固有名詞なしで一般原則へ変換
4. **Transfer** — 別ジャンルでどう使えるか考える
5. **Test** — プレイテストで検証できる質問へ変える

### 例

避ける:
> ある特定ゲームのステージ構成・敵配置・攻略手順を詳しく再現する。

残す:
> 新しいルールは安全な状況で提示し、単独練習の後に既存ルールと組み合わせると学習曲線を作りやすい。

## 引用

引用が必要な場合は最小限にする。知識本体は引用に依存させない。

原則:
- 引用より自分の分析を中心にする
- 元資料へのリンクを付ける
- 引用部分と自分の分析を明確に分ける
- 原文を連続して保存しない
