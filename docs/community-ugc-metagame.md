# Community, UGC & Metagame

攻略誌、高得点文化、対戦攻略、Construction Setなどから抽象化した、ゲーム外の学習と制作をゲーム寿命へ接続する設計。

## 1. Metagame

ゲーム外で、
- 強い戦法発見
- 対策共有
- 対策への対策
が続くと、コンテンツを追加しなくても戦略が変化する。

必要なのは「唯一の永久正解」を作らないこと。

## 2. Shareable knowledge

共有価値があるもの:
- マッチアップ知識
- スコアルート
- 隠し条件
- ビルド
- 高難度解法
- 発見したテクニック

単なる答えより、他の人が応用できる知識が強い。

## 3. Unexpected techniques

想定外テクニックを分類する。

残す候補:
- 技能が必要
- 対抗可能
- 選択を増やす
- 観戦して面白い

削除候補:
- 無限安全
- 対抗不能
- 進行破壊
- 競争の公平性破壊

## 4. UGC loop

良いエディタは、

Create → Test → Revise → Share → Learn

を短く回せる。

## 5. Templates first

白紙から作らせるより、
- 既存面コピー
- テンプレート
- プリセット
から始めると制作開始が速い。

## 6. Use internal-quality tools carefully

内部制作ツール級の表現力は強いが、そのままでは複雑すぎることがある。

Basic / Advancedを分ける。

## 7. Discovery system

UGCには投稿機能だけでなく、
- 新着
- 小規模作品
- タグ
- 難度
- プレイ時間
など発見導線が必要。

## 8. Replays as learning media

リプレイは記録ではなく教材になる。

- 入力表示
- 速度変更
- 巻き戻し
- 特定場面ジャンプ
があると学習効率が上がる。

## Playtest

- 強い戦法に次の回答が生まれる余地があるか
- UGC一作を作り始めるまで何分か
- Create→Test往復は何秒か
- 想定外技を「想定外だから」という理由だけで削除していないか
- 他人のリプレイから改善点を理解できるか
