# Returning Player Recalibration

長期休止したプレイヤーを、古いskill estimateへ固定せず、公平に再導入する。

## 1. Skill estimate has uncertainty

Ratingは「実力そのもの」ではなく推定値。

休止期間が長いほど、
> 今も同じ強さである確信
は下がる。

## 2. Decay confidence, not skill

復帰したからといってskill ratingを大幅に下げる必要はない。

confidenceを下げて、
- 数試合の結果へ速く反応
させる方が自然。

## 3. Avoid fixed assumptions

休止後に弱いとは限らない。

- similar game experience
- retained mechanics
- coaching
で維持／向上している場合もある。

## 4. Calibration phase

最初の数戦はrating adjustmentを速くする。

必要なら、
- placement-like matches
- hidden recalibration
を使う。

## 5. Warm-up before ranked

復帰導線:
1. controls recap
2. short practice
3. current meta summary
4. optional unranked
5. ranked

すぐ競技戦へ投げ込まない。

## 6. Track returner telemetry

比較:
- first 10 match win rate
- quit rate
- rating movement
- opponent skill
- queue time

通常ユーザーとの差を見る。

## 7. Season reset separation

分ける:
- visible rank
- reward track
- MMR
- uncertainty
- seasonal placement

全resetを同じにしない。

## 8. Abuse resistance

休止で意図的に弱い相手と当たりやすくなるなら悪用可能。

confidence changeを使い、
直接ratingを落としすぎない。

## 9. Group play

復帰者 + 現役友人で遊ぶ場合、
skill mismatchが大きくなる。

casual mode、wide grouping、trainingなど、ranked以外の再合流導線を用意する。

## Checklist

- 長期休止でconfidenceが変わるか
- 数戦でratingが現在skillへ追従できるか
- 復帰者の最初の10戦が極端に不公平でないか
- warm-up導線があるか
- season resetがMMR完全消去になっていないか
- abuse可能なreturner bonusがないか
