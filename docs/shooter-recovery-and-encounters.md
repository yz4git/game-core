# Shooter Recovery & Encounter Design

シューティングの敵配置・パワー曲線・死亡後の復帰を一つの流れとして設計する。

## 1. Power curve

パワーアップは単純なDPS上昇にしない。

- 正面火力
- 広範囲
- 地形対応
- 防御
- 移動
- 得点
などの用途差を作る。

ステージ形状によって「今回は何を取るか」が変わることが理想。

## 2. Death creates a new game state

死亡後に装備を失うゲームでは、その瞬間から別の難易度になる。

各チェックポイントを最低装備からテストする。

チェック:
- 最初の30秒に回復資源があるか
- 高火力前提の敵耐久になっていないか
- 安全な立て直し手段があるか
- 一回の死が次の死を確定させないか

## 3. Flow-preserving restart

失敗後、
- 同じ長い導入
- 低密度区間
- 演出
を再度強制しない。

難しい区間ほど再挑戦を短くする。

## 4. Enemy rhythm

敵配置を音楽のように見る。

- 提示
- 増加
- 組み合わせ
- 解放
- 呼吸
- 再上昇

敵数を均等に置かない。

## 5. Screen control

敵ごとに「画面のどの領域を使えなくするか」を見る。

- 横移動を止める
- 上下を分断する
- 前方を塞ぐ
- 後方確認を要求する

弾数ではなく安全領域の形を変える。

## 6. Survival vs score

通常クリアの安全行動と、高得点の危険行動を少し分ける。

例:
- 近距離撃破
- 連続撃破
- 危険ルート
- 資源温存

初心者は生存でき、上級者は自分から危険を増やせる。

## 7. Bomb / emergency resource

緊急回避資源は「使わないのが正義」だけにしない。

- 使うと失う得点
- 抱えたまま死ぬ損失
- 追加攻撃用途
など複数の価値を持たせる。

## 8. Playtest questions

- 全チェックポイントを最低装備で突破できるか
- 一回の死亡から復帰できる割合はどれくらいか
- 20秒間同じ敵密度が続いていないか
- 高得点行動は生存行動と少し違うか
- ボムを使う判断が存在するか
