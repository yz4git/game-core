# Layered Accessibility & Depth

初心者がすぐ遊べることと、上級者が長く掘れることを両立するための設計。

## Three-layer target

### Layer 1 — Immediate
最初の30秒〜数分。

必要:
- 何を操作するか分かる
- 一つ成功できる
- 主入力が気持ちいい
- 失敗理由が大まかに分かる

### Layer 2 — Tactical
数十分〜数時間。

増えるもの:
- 敵役割
- リスク／報酬
- 位置取り
- 資源管理
- 装備や技の組み合わせ

### Layer 3 — Mastery
長期。

残すもの:
- スコア最適化
- タイム短縮
- 高難度
- 高度なAI誘導
- 高効率ルート
- キャラ差
- 特殊条件

## Progressive disclosure

最初から全部表示しない。

候補:
- 詳細ステータスを折りたたむ
- 自動装備を初期ON
- 高度設定は二段目
- 基本操作を少数にする
- 上級入力を説明後に開示

## Quick mode / Full mode

同じコアを保ったまま、情報量や準備量を変える。

Quick:
- 即開始
- 推奨設定
- 少ない管理

Full:
- 詳細編成
- 手動設定
- 高度戦略

重要なのはQuickを「劣化版」にしないこと。

## Complexity budget

新しい要素を一つ追加したら確認する。

- 新しい判断が増えたか
- 覚える用語だけ増えていないか
- 既存要素と相互作用するか
- 初心者へ最初から見せる必要があるか

## Mastery without exclusion

上級者向け深さを作る際、初心者の基本操作を難しくしすぎない。

例:
- 普通の回避は簡単
- 完璧回避は高難度
- 通常ドリフトは簡単
- 最速ライン維持は高難度

同じ基本動作の中に技能差を作る。

## Final test

- 初心者: 何をしていいか分かるか
- 中級者: なぜ勝てたか分かるか
- 上級者: まだ改善できる点が見えるか
