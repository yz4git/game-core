# Accessibility Options

難易度を一つの数値として扱わず、プレイヤーが困難を感じる要因ごとに調整できるようにする。

## 1. Separate challenge dimensions

負荷を分けて考える。

- reaction speed
- precision
- repeated input
- visual readability
- audio dependence
- memory
- planning
- resource pressure

Easy/Hardだけでは、必要ない要素まで変えてしまう。

## 2. Preserve the core

Assistで中心体験を完全に自動化しない。

例:
- 反応が厳しい → speed down
- stamina操作が厳しい → infinite stamina
- 被弾が厳しい → damage reduction

できるだけ、ゲームの中心判断を残す。

## 3. Redundant communication

重要情報は複数チャンネルで伝える。

- color + shape
- sound + visual marker
- vibration + icon

一つの感覚だけに依存しない。

## 4. Controls

検討:
- full remap
- hold / toggle
- sensitivity
- dead zone
- rapid input assist
- larger touch targets

## 5. Speed control

ゲーム速度調整は、
- 認知
- 反応
- 精密入力
を同時に緩められる。

ただし物理、アニメーション、音楽同期が壊れないよう統一的に扱う。

## 6. Presets + granular settings

最初に分かりやすいAssist presetを用意し、必要なら個別設定へ進める。

大量スライダーだけを初心者へ見せない。

## 7. No shame

Assist利用に、
- スコア剥奪
- 警告文
- 低いランク名
など不要な羞恥を結びつけない。

競技記録を分ける必要がある場合は、事実として条件を表示する。

## Playtest

- Assist後も何を学ぶゲームか説明できるか
- 色覚差でも重要情報が読めるか
- 片手／異なる入力構成で遊べるか
- speed downで物理が破綻しないか
- どの設定を変えるべきか初見で分かるか
