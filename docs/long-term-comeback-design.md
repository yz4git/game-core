# Long-Term Comeback Design

長期ゲームで、毎日触る義務ではなく「いつ戻っても続けられる」構造を作る。

## 1. Positive framing

同じ数値システムでも、

悪い:
- 連続プレイするとXPが減る

良い:
- 休むとRested XPが貯まる

のように、休止を罰ではなくボーナスとして表現できる。

## 2. Rested progress

休止期間に、
- XP bonus
- resource bonus
- catch-up token
を蓄積し、復帰直後の進行を滑らかにする。

上限を持たせ、永遠に貯まり続ける必要はない。

## 3. Comeback floor

復帰時に現在コンテンツへ参加できる最低ラインを保証する。

- starter gear
- temporary boost
- tutorial recap
- free respec

継続プレイヤーの最高到達点まで自動で追いつかせる必要はない。

## 4. Preserve veteran value

常時プレイヤーには、
- mastery
- collection
- records
- cosmetics
- knowledge
が残るようにする。

catch-upで全差を消さない。

## 5. Re-entry tutorial

数週間〜数か月休んだ人向けに、
- current objective
- controls recap
- recent systems
- recommended build
を短く提示する。

## 6. Return triggers

戻る理由:
- new content
- social invitation
- rested bonus
- unfinished goal

通知を「今来ないと損」としすぎない。

## 7. Seasonal resets

season resetを使う場合、
失うもの／残るものを明確に分ける。

残す候補:
- account mastery
- cosmetics
- achievements
- historical records

毎回ゼロから同じ作業をさせない。

## 8. Multiple progression clocks

すべてをdaily cadenceへ載せない。

混ぜる:
- permanent progression
- seasonal progression
- optional daily
- mastery track

休むと完全に置いていかれる一本線を避ける。

## 9. Return without shame

復帰UIは、
- missed rewards
- lost streak
を強調するより、
- what is new
- what you can do now
を中心にする。

## Playtest

- 1週間休んだ後、何分で本編へ戻れるか
- 1か月休止後に目標を理解できるか
- rested bonusがregular playを無意味にしないか
- season resetで同じ作業を強制しすぎないか
- 戻った瞬間に「失ったもの」ばかり見せていないか


## 10. Rating confidence decay

長期休止後、過去MMRを即座に捨てる必要はない。

代わりに、
> このMMRが現在も正しいという確信
を下げる。

再開後の数試合でratingが通常より速く調整される状態にする。

## 11. Do not assume skill loss

休止中に、
- similar games
- practice elsewhere
- retained motor skill
があるかもしれない。

復帰者を一律に低ランクへ落とすのではなく、再校正を速める。

## 12. Warm-up route

rankedへ入る前に、
- training
- unranked
- bot match
- short recap
へ自然に誘導できる。

必須化しすぎず、skill memoryを戻す場所を提供する。

## 13. Return matchmaking telemetry

復帰者について、
- first 10 match win rate
- opponent MMR
- rating movement
- quit rate
を通常プレイヤーと比較する。

復帰直後だけ極端に悪い場合は再校正設計を疑う。

## 14. Season reset separation

区別する:
- reward/progression reset
- rank compression
- hidden skill estimate
- confidence reset

全部を同じresetへまとめない。

## 15. Comeback abuse resistance

復帰補正が、
- intentional inactivity
- smurfing
- deranking
の利益になりすぎないようにする。

確信度調整はskillを直接下げるより悪用されにくい場合がある。
