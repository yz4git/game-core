# Puzzle Planning

パズルを「正解を知る」だけでなく、未来を読み、仮説を試す遊びとして設計する。

## 1. Planning horizon

どこまで未来を見せるかでゲーム性が変わる。

- 未来なし: 反応中心
- 次1手: 短期計画
- 複数手: 長期計画
- 確率表示: リスク計画

未来情報は簡単化ではなく、現在の行動へ意味を増やす。

## 2. Immediate and long-term value

一つの手に、
- 今すぐ盤面を安全にする価値
- 数手後を良くする価値
を持たせる。

短期と長期が競合すると深さが出る。

## 3. Player-controlled tempo

熟練者が自分で速度を上げられる仕組みを検討する。

- ハードドロップ
- 早送り
- 短い制限時間を選ぶ
- 追加リスクで倍率を上げる

上級者の待ち時間を減らしつつリスクを増やせる。

## 4. Reset cost

仮説検証が核ならリセットを速くする。

失敗 → 再試行までの長い演出やロードは思考を切る。

## 5. New rules should expand the original question

続編・後半ルールは、元の判断を置き換えるのではなく広げる。

例:
- 下からせり上がる地形
- 爆発ピース
- 二人協力
などを追加する場合でも、基本の配置判断が引き続き重要であること。

## 6. Multiple solutions

可能なら、唯一の正解だけでなく、
- 安全
- 最短
- 高得点
- 美しい配置
など異なる解を許す。

## 7. Playtest questions

- 次情報を一つ増やすと計画が生まれるか
- 現在の最適手と長期の最適手が時々違うか
- リセットまで何秒か
- 新ルールで旧ルールが不要になっていないか
